# 计算方法实验报告：拉格朗日插值与牛顿插值比较

**实验名称**：高阶插值的病态性与龙格现象
**实验函数**：f(x) = 1/(1+x²)，定义域 [-5, 5]

---

## 一、实验目的

1. 理解插值多项式的存在唯一性，掌握拉格朗日插值与牛顿插值的构造方法；
2. 编写拉格朗日插值与牛顿插值函数，对给定函数进行插值计算并绘图；
3. 通过实验观察高阶等距节点插值的病态性，复现龙格（Runge）现象。

## 二、插值原理

### 2.1 问题形式

给定 n+1 个节点 (x₀, y₀), (x₁, y₁), …, (xₙ, yₙ)（节点互异），求次数不超过 n 的多项式 Pₙ(x) 使

$$P_n(x_i) = y_i, \quad i = 0, 1, \dots, n.$$

由 n+1 个线性方程确定 n+1 个系数，系数矩阵（范德蒙德型）在节点互异时非奇异，故**插值多项式存在且唯一**。这一定理保证：拉格朗日形式与牛顿形式只是同一多项式的两种等价写法，本实验从数值上验证了这一点（见 4.2）。

### 2.2 拉格朗日插值

构造基函数 lᵢ(x)（满足 lᵢ(xⱼ) = δᵢⱼ）：

$$l_i(x) = \prod_{j \ne i} \frac{x - x_j}{x_i - x_j}, \qquad L_n(x) = \sum_{i=0}^{n} y_i \, l_i(x).$$

程序实现（`lagrange.py`）：`lagrange_eval` 按基函数法逐点求值；`poly_coefficients` 用 `np.polymul` 累乘分子多项式并除以分母，将插值式展开为标准系数形式（`np.polymul` 返回最高次在前，需反转为升幂累加）。

### 2.3 牛顿插值

由**差商**递推定义（f[x₀,…,xₖ] 为 k 阶差商）：

$$N_n(x) = f[x_0] + f[x_0,x_1](x-x_0) + \cdots + f[x_0,\dots,x_n]\prod_{i=0}^{n-1}(x-x_i).$$

以课程四点样例 (1,3), (2,7), (4,19), (7,55) 为例，差商表逐列递推：

| xᵢ | f | 一阶 | 二阶 | 三阶 |
|---|---|---|---|---|
| 1 | 3 | | | |
| 2 | 7 | 4 | | |
| 4 | 19 | 6 | 2/3 | |
| 7 | 55 | 12 | 6/5 | 4/45 |

取**首行** [3, 4, 2/3, 4/45] 为系数（与 `newton.py` 的 doctest 一致）。求值用**嵌套乘法**（秦九韶算法），从最高阶项向内套算，只需 n 次乘法。

牛顿形式的优点：**新增节点只需在差商表末尾追加一列，已有系数不变**——本实验程序在交互演示中利用了该性质。

### 2.4 余项

$$R_n(x) = f(x) - P_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}\prod_{i=0}^{n}(x - x_i), \quad \xi \in (\min x_i, \max x_i).$$

余项由两个因子共同决定：f 的 n+1 阶导数，与连乘因子 ∏(x−xᵢ)。龙格现象正是这两个因子在等距节点下协同恶化的结果（见第五节）。

## 三、实验设置

| 项目 | 内容 |
|---|---|
| 插值函数 | f(x) = 1/(1+x²) |
| 区间 | [-5, 5] |
| 节点 | n+1 个等距节点（xᵢ = −5 + 10i/n） |
| 算法 | 拉格朗日（基函数法）、牛顿（差商表 + 嵌套乘法） |
| 误差度量 | 密网格（2001 点）上最大绝对误差 max|f(x) − Pₙ(x)| |

**程序结构**（Python + matplotlib，函数级单文件职责）：

## 四、实验结果

### 4.1 插值效果：次数升高反而在两端发散

![n=5 与 n=11 等距节点插值对比](../figures/runge_compare.png)

- n=5：插值曲线基本贴住原函数，仅在中部略有偏差；
- n=11：**区间内部拟合更好，但两端 |x| ≈ 4~5 出现剧烈振荡**，振幅远超原函数——即龙格现象。

### 4.2 正确性验证（两种插值法互相印证）

| 验证项 | 结果 |
|---|---|
| 过点误差 max|P(xᵢ)−yᵢ| | ≤ 1e-12（机器精度量级） |
| 拉格朗日 vs 牛顿（区间内随机点） | 最大差 < 1e-9（同一多项式的两种写法） |
| 牛顿加点后旧系数 | 逐位不变（差商表增量性） |
| 差商表 vs 手算 | [3, 4, 2/3, 4/45] 完全一致 |

### 4.3 误差随次数 n 的变化

| n | 3 | 5 | 7 | 9 | 11 | 15 | 20 | 30 |
|---|---|---|---|---|---|---|---|---|
| 最大误差 | 0.707 | 0.433 | 0.247 | 0.300 | 0.557 | 2.108 | 59.82 | 2388.0 |

![最大误差随 n 变化（对数坐标）](../figures/runge_error.png)

n=3→7 误差缓慢下降（低次时的正常收敛假象），**n≥9 起转为上升，n=20 后指数级爆炸**。误差不随节点加密而收敛，等距高阶插值对这类函数是**发散**的。

### 4.4 区间端点的具体对照（x = 4.5 处）

| n | 真值 f(4.5) | 插值 Pₙ(4.5) | 绝对误差 | 偏差倍数 |
|---|---|---|---|---|
| 11 | 0.0471 | 0.4524 | 0.405 | 9 倍 |
| 30 | 0.0471 | −77.291 | 77.34 | 1643 倍 |

n=30 时插值在真值仅为 0.047 的点给出 **−77.3**，且符号相反；连乘因子 |∏(4.5−xᵢ)| 已达 1.12×10¹⁵。

## 五、分析与讨论

**（1）龙格现象的机理。** 由余项公式，误差取决于 f^{(n+1)}(ξ)/(n+1)! 与 ∏(x−xᵢ) 之积。对 f(x)=1/(1+x²)（复平面上在 x=±i 处有奇点），其高阶导数在 |x| > 3.63 一带随 n 指数增长；而等距节点的连乘因子在区间两端取值最大（本实验 x=4.5、n=30 处达 10¹⁵ 量级）。两因子相乘，误差便集中在两端爆炸，中部反而收敛良好——与图 1 中"中间贴合、两端翘起"的形态完全吻合。

**（2）高阶插值的病态性。** 上述发散是等距高阶插值**固有的数学性质**，不是实现误差；但计算层面的病态同样真实存在：

| n | 勒贝格常数 Λₙ | 范德蒙德条件数 κ₂(V) |
|---|---|---|
| 5 | 3.1 | 3.8×10³ |
| 9 | 17.8 | 5.1×10⁶ |
| 11 | 51.2 | 1.9×10⁸ |
| 15 | 512.3 | 2.9×10¹¹ |
| 20 | 10986.5 | 3.1×10¹⁵ |

- 勒贝格常数 Λₙ = maxₓ Σᵢ|lᵢ(x)| 是插值算子的条件数：节点值上大小为 δ 的扰动，在输出端最多放大 Λₙ 倍。等距节点下 Λₙ 随 n 指数增长（n=20 时已达 1.1 万倍）；
- 以系数为未知数的线性方程组（范德蒙德方程）条件数在 n=20 时达 10¹⁵，逼近双精度极限，系数解在数值上已不可信；
- 本实验中拉格朗日与牛顿两种形式均基于节点值（而非系数方程组），求值过程条件数相同（均受 Λₙ 支配），故两者数值差 <1e-9——差异不在形式，而在节点分布。

**（3）两点辨析。**
- 单点扰动不会被放大：|lᵢ(x)| ≤ 1 恒成立，改动一个节点值曲线变化至多 δ。病态性体现在**整体的 Λₙ**（多点微扰最坏情形），而非单点；
- 误差发散与数值病态相互独立又相互叠加：前者换非等距节点（如切比雪夫点）即可消除，后者（Λₙ、κ₂ 增长）是多项式插值问题本身的属性，换节点只能缓解不能根除。本实验按任务书范围只做等距节点，未展开此对比。

## 六、结论

1. 拉格朗日插值与牛顿插值由多项式唯一性定理保证等价，实验数值差 <1e-9；牛顿形式凭借差商表的增量性，在"逐个加点"的场景下更自然；
2. 对 f(x)=1/(1+x²) 在 [-5,5] 上做等距高阶插值，n≥9 后最大误差随 n 指数增长（n=30 达 2388），端部出现符号反转与百倍千倍偏差——复现了龙格现象；
3. 高阶插值的病态性由勒贝格常数（n=20 时 1.1×10⁴）与范德蒙德条件数（n=20 时 3.1×10¹⁵）量化刻画，与余项中连乘因子的端部爆炸共同解释了"节点越密、误差越大"的反直觉结果；
4. 实践含义：多项式插值应控制次数、慎用高次等距插值；需要整体逼近时优先考虑低次分段（本实验未展开）。
