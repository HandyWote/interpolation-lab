## 三、概念逐个拆解

### 1. 插值（Interpolation）

给定 $n+1$ 个数据点 $(x_0,f_0),\dots,(x_n,f_n)$，找一个多项式 $P(x)$，使它**必须穿过每一个点**，即 $P(x_i)=f_i$ 对所有 $i$ 成立。满足该条件、次数不超过 $n$ 的多项式**唯一存在**。

用途：用离散采样点近似连续函数，或补全缺失数据。

### 2. 拉格朗日插值（Lagrange）

构造一组"开关式"基函数：

$$l_i(x)=\prod_{j\neq i}\frac{x-x_j}{x_i-x_j},\qquad L_n(x)=\sum_{i=0}^{n} f_i\, l_i(x)$$

$l_i(x)$ 在自己那个节点上等于 1，在其他所有节点上等于 0。

- **优点**：公式对称紧凑，与节点排列顺序无关，便于理论推导（误差项就是靠它推的）。
- **缺点**：每增加一个新节点，所有基函数都要重算，计算量 $O(n^2)$，不适合"逐点增加数据"。

### 3. 牛顿插值（Newton）

用**差商**写成：

$$N_n(x)=f[x_0]+f[x_0,x_1](x-x_0)+f[x_0,x_1,x_2](x-x_0)(x-x_1)+\cdots$$

差商递推表：

$$f[x_i,\dots,x_{i+k}]=\frac{f[x_{i+1},\dots,x_{i+k}]-f[x_i,\dots,x_{i+k-1}]}{x_{i+k}-x_i}$$

- **优点**：**增加一个节点只需在末尾追加一项**，前面系数不变，天然适合递推和编程（先建差商表，再用 Horner 法求值）。
- 数学上 $N_n(x)\equiv L_n(x)$：**同一条曲线，只是配方不同。**

> **"比较"的核心结论**：两者结果完全一致（数值差在机器精度量级，约 $10^{-14}$），差别在计算结构与效率——牛顿形式可增量更新、稳定性略好；拉格朗日形式便于理论分析。

### 4. 高阶插值

指节点数量多、多项式次数高（几十次）。直觉上"次数越高越准"，但事实相反，这正是本实验要打破的误解。

### 5. 病态性（Ill-conditioning）

**病态 = 输入稍微一动，输出就天翻地覆。**

- **这是"问题本身"的先天体质，不是你算法写错了。**
- 代数层面：范德蒙德矩阵条件数随 $n$ 指数增长（$\kappa(V)\sim 2^n$ 量级）；
- 几何层面：节点位置或函数值的微小误差被放大成多项式的剧烈摆动。
- 区分：**病态**是问题固有属性；**不稳定**是算法（舍入误差放大）造成的。

### 6. 龙格现象（Runge Phenomenon）

**等距节点 + 高阶插值时，区间两端出现剧烈振荡，且 $n\to\infty$ 时误差不收敛到 0。**

经典反例（Carl Runge, 1901）：

$$f(x)=\frac{1}{1+25x^2},\quad x\in[-1,1]$$

在 $[-1,1]$ 上取 $n+1$ 个**等距**节点插值：中间部分温度很高、很乖，一旦靠近 $|x|=1$ 就开始疯狂上下甩，误差越来越大。

**成因（报告理论部分）：** 误差公式

$$f(x)-L_n(x)=\frac{f^{(n+1)}(\xi)}{(n+1)!}\prod_{i=0}^{n}(x-x_i)$$

中 $\prod(x-x_i)$ 在区间边缘取值很大；更本质的刻画是**勒贝格常数**

$$\Lambda_n=\max_{x}\sum_i|l_i(x)|$$

对等距节点随 $n$ 指数增长，插值算子范数发散。

**解决办法（写进报告是加分项）：**

| 方法 | 说明 |
| --- | --- |
| 切比雪夫节点 | $x_k=\cos\frac{2k+1}{2(n+1)}\pi$，两端加密，$\Lambda_n$ 只按 $\log n$ 增长，龙格现象消失 |
| 分段低次插值 | 分段线性、分段三次，不用一根长曲线穿所有点 |
| 三次样条 | 保证二阶导数连续，工程上最常用 |

## 五、必须修正的三处（报告/答辩别踩坑）

### 1. 是"插值"，不是"拟合"

| | 插值 Interpolation | 拟合 Fitting |
| --- | --- | --- |
| 曲线要求 | **必须穿过**每一个点 | 只求"大致贴合"，可以不过点 |
| 典型方法 | 拉格朗日、牛顿、样条 | 最小二乘、直线回归 |
| 点的性质 | 点是**精确的**，必须遵守 | 点有误差，可以不信 |

说成"拟合"会被认为概念不清。

### 2. 是"龙格"，不是"升格"

Runge 现象，中文常写"龙格现象"，也译"朗格现象"。

### 3. 病态性 ≠ 龙格现象（最关键）

二者是**原因与表现**的关系：

- **病态性**：问题本身的"先天体质"，输入微小扰动被放大成巨大输出偏差 —— **病因**；
- **龙格现象**：在"等距节点 + 高阶插值"这一特定场景下病态性露出的马脚 —— **症状**。

**把这层关系讲清楚，可以顺带回答一个更深的问题：** 换成切比雪夫节点后龙格现象消失了，但"病态性"其实并没有被彻底消灭，只是被压住了 —— 这个回答会让老师眼前一亮。

## 七、实验步骤（对应任务书）

1. 取 $f(x)=\dfrac{1}{1+25x^2}$，$x\in[-1,1]$，等距节点，$n=5,10,15,20$。
2. 分别用拉格朗日函数和牛顿函数插值，在细网格上求值，**比较两者差值**（应为机器精度量级）。
3. 画出原函数、插值曲线、节点位置 —— 观察端点振荡（龙格现象）。
4. 画误差随 $n$ 的变化曲线（对数坐标），说明误差不收敛。
5. **附加实验**：换成切比雪夫节点，重复步骤 3–4，对比振荡消失。
